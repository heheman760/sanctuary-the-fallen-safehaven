# Sanctuary: The Ashen Bell

This repository contains a playable Godot 4 prototype for a dark-fantasy action RPG inspired by the feeling of ancient ruin, sacred vows, and demon-haunted sanctuaries.

## Story
The city of Sablemere once stood beneath the protection of the Ashen Bell, a sacred relic rumored to hold the last light of the old gods. When the night-walkers descended, the bell was buried beneath the sanctuary ruin. Every prayer failed. Every gate was sealed. Only one sworn keeper remains.

You are that keeper. Fight through the ruined square, defeat the wraiths, break the Ember Gate, and wake the Ashen Bell before the abyss swallows the world.

## Current features
- top-down movement
- sword attack
- enemy AI
- health and score systems
- story-driven quest progression
- original dark-fantasy setting

## How to run
1. Open this folder in Godot 4.x.
2. Import the project.
3. Press F5 to play.

## Controls
- W/A/S/D: move
- Space: attack
- Enter: advance story text
