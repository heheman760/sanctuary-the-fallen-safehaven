# Sanctuary: The Ashen Bell

This repository contains a small Godot 4 starter prototype inspired by dark-fantasy action RPGs such as Diablo, but built with original story and gameplay.

## Features
- Top-down movement
- Sword swing attack
- Enemy AI
- Health system
- Story HUD
- Original dark-fantasy setting called "The Ashen Bell"

## How to run
1. Open this folder in Godot 4.x.
2. Import the project.
3. Press F5 or click Run.

## Story premise
The sanctuary has fallen. A forgotten bell sleeps beneath the ruins, and only one oathkeeper remains to wake it.
